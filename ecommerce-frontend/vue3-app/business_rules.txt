============================================
E-Shop 电商平台 业务规则文档
============================================

【一、认证与授权规则】

1. 用户登录成功后，JWT token 存储在 localStorage 中，键名为 'token'
2. 每次 HTTP 请求通过 axios 请求拦截器自动在 Authorization 头中添加 Bearer token
3. 当后端返回 401 状态码时，响应拦截器自动清除 localStorage 中的 token 并跳转到 /login 登录页
4. 需要登录的页面（购物车 /cart、订单列表 /orders、订单详情 /order/:id）通过路由 meta.requiresAuth 标记
5. 全局前置路由守卫检查 requiresAuth 标记的路由，若 localStorage 中无 token 则重定向到 /login
6. 退出登录时清除 localStorage 中的 token 并跳转到 /login

【二、验证规则】

1. 商品详情页数量输入不可小于 1，若用户输入小于 1 自动修正为 1
2. 购物车中商品数量不可小于 1，减少按钮在数量为 1 时禁用
3. 购物车数量修改输入框仅接受 >= 1 的整数值
4. 加入购物车前必须检查登录状态，未登录则跳转到 /login

【三、数据规则】

1. 商品列表支持三种查询方式：普通分页列表、关键词搜索、标签筛选
2. 分页从第 0 页开始，默认每页 12 条
3. 购物车操作包括：查看、添加商品、修改数量（增/减/直接输入）、删除商品
4. 提交订单基于当前用户购物车内容创建，成功后跳转到订单列表页
5. 用户注册需要提供用户名、密码、邮箱三个字段
6. 登录需要提供用户名和密码

【四、显示规则】

1. 商品卡片价格显示格式：¥符号 + 整数部分（千分位格式化）+ 小数点 + 两位小数
2. 商品详情页库存 <= 5 时，库存数字显示为红色加粗（low-stock 样式）
3. 标签映射关系：TODAY_DEAL → "🔥 今日特惠"、NEW → "✨ 新品上市"、HOT → "🏆 热销排行"、BRAND → "💎 品牌精选"
4. 搜索结果页显示搜索关键词和商品总数
5. 标签筛选页显示标签名称和商品总数
6. 无搜索/无标签时显示 Hero Banner 和 "为你推荐" 标题
7. 商品列表为空时显示 "📦 暂无商品数据"
8. 购物车为空时显示 "购物车是空的，快去挑选商品吧！" 和 "去购物" 按钮
9. 订单列表为空时显示 "暂无订单记录" 和 "去购物" 按钮
10. 商品卡片图片加载失败时使用 picsum.photos 默认图片
11. 订单状态标签颜色：CREATED 蓝色、PAID 绿色、CANCELLED 灰色
12. 操作成功提示为绿色背景，操作失败提示为红色背景

【五、导航规则】

1. 首页 "/" 自动重定向到 "/products"
2. Header 搜索栏输入关键词后按 Enter 或点击搜索按钮，跳转到 /products?keyword=xxx
3. Header 子导航栏点击标签链接，跳转到 /products?tag=XXX
4. 商品卡片点击跳转到 /product/:id 详情页
5. 登录成功跳转到 /products
6. 注册成功后 1.5 秒自动跳转到 /login
7. 提交订单成功跳转到 /orders
8. 订单卡片点击跳转到 /order/:id 详情页
9. 分页切换后页面滚动到顶部（smooth 滚动）
10. 路由查询参数变化时自动重新加载商品列表（watch $route.query）
11. 路由参数 id 变化时自动重新加载商品详情（watch $route.params.id）
