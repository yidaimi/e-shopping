================================================================================
BUSINESS RULES - E-Shop Ecommerce Platform
================================================================================
Extracted from Vue 2 source code analysis.

## Authentication & Authorization

BR-AUTH-01: JWT tokens are stored in localStorage under the key "token".
BR-AUTH-02: All HTTP requests automatically include the "Authorization: Bearer <token>" header via axios request interceptor when a token exists in localStorage.
BR-AUTH-03: When a 401 Unauthorized response is received, the token is removed from localStorage and the user is redirected to the login page (/login).
BR-AUTH-04: Routes with meta.requiresAuth = true require a valid token in localStorage. If no token is found, the user is redirected to /login.
BR-AUTH-05: The following routes require authentication: /cart, /orders, /order/:id.
BR-AUTH-06: The following routes are public: /products, /product/:id, /login, /register.
BR-AUTH-07: Adding items to cart requires login. If not logged in, the user is redirected to /login.

## Validation Rules

BR-VAL-01: Login requires both username and password fields.
BR-VAL-02: Registration requires username, password, and email fields.
BR-VAL-03: Cart item quantity must be at least 1. Quantities below 1 are rejected.
BR-VAL-04: Product detail page quantity input has min=1 and max=product.stock constraints.
BR-VAL-05: When product detail quantity is changed to less than 1, it is reset to 1.

## Data Rules

BR-DATA-01: Products are paginated with a default page size of 12 items per page.
BR-DATA-02: Pagination is 0-based (first page = 0).
BR-DATA-03: Product search supports keyword-based search via the /api/product/search endpoint.
BR-DATA-04: Products can be filtered by tags: TODAY_DEAL, NEW, HOT, BRAND.
BR-DATA-05: Tag labels map as follows: TODAY_DEAL="🔥 今日特惠", NEW="✨ 新品上市", HOT="🏆 热销排行", BRAND="💎 品牌精选".
BR-DATA-06: Cart automatically calculates subtotal per item and totalPrice for the entire cart (server-side).
BR-DATA-07: Product list API returns { data: { list: [...], total: N } } structure.
BR-DATA-08: Login API returns { data: "<jwt-token>" } and the token is extracted from res.data.

## Workflow Rules

BR-FLOW-01: After successful registration, a success message is shown and the user is redirected to the login page after 1.5 seconds (1500ms setTimeout).
BR-FLOW-02: After successful login, the user is redirected to the product list page (/products).
BR-FLOW-03: Adding to cart requires login check first. If not logged in, redirect to /login.
BR-FLOW-04: After submitting an order, the user is redirected to the order list page (/orders).
BR-FLOW-05: On logout, the token is removed from localStorage and the user is redirected to /login.
BR-FLOW-06: When the route query parameters change (keyword or tag), the product list reloads from page 0.
BR-FLOW-07: Page scroll is smoothly reset to top when pagination changes.

## Display Rules

BR-DISP-01: Product prices are displayed split into whole and decimal parts: ¥<whole>.<decimal>.
BR-DISP-02: Price whole part uses toLocaleString() for formatting (e.g., 1,234).
BR-DISP-03: Price decimal part is extracted using (price % 1).toFixed(2).substring(2).
BR-DISP-04: When a product image fails to load, a default image from picsum.photos is used.
BR-DISP-05: Stock quantity ≤ 5 is displayed in red with bold font (low-stock class).
BR-DISP-06: The hero banner is shown only when there is no search keyword and no tag filter active.
BR-DISP-07: "为你推荐" section title is shown only when there is no keyword and no tag filter.
BR-DISP-08: Empty state shows 📦 icon with "暂无商品数据" when no products are found.
BR-DISP-09: Loading state shows "加载中..." during product fetch.
BR-DISP-10: Pagination component only shows when total > pageSize.
BR-DISP-11: Header shows logged-in state (orders link + logout) or logged-out state (login + register links) based on token presence.
BR-DISP-12: Each order card shows order ID, status badge (CREATED=blue, PAID=green, CANCELLED=gray), total amount, and creation time.
BR-DISP-13: Product cards show star rating (★★★★☆), stock count, and "免费配送" delivery text.

## Limits & Constraints

BR-LIMIT-01: API request timeout is set to 15000ms (15 seconds).
BR-LIMIT-02: Product list page size is fixed at 12.
BR-LIMIT-03: Cart quantity minimum is 1 (enforced both client-side and server-side).
