================================================================================
APPLICATION FLOWS - E-Shop Ecommerce Platform
================================================================================
Extracted from Vue 2 source code analysis.

## Flow 1: User Registration

1. User navigates to /register
2. User enters username, password, and email
3. User clicks "注册" button
4. System calls POST /api/user/register with { username, password, email }
5a. SUCCESS: Success message "注册成功，即将跳转到登录页..." is displayed
    → After 1.5 seconds, user is redirected to /login
5b. FAILURE: Error message from server response (or "注册失败，请稍后重试") is displayed
    → User stays on /register page

## Flow 2: User Login

1. User navigates to /login
2. User enters username and password
3. User clicks "登录" button
4. System calls POST /api/user/login with { username, password }
5a. SUCCESS: JWT token is extracted from response (res.data) and saved to localStorage("token")
    → User is redirected to /products
5b. FAILURE: Error message from server response (or "登录失败，请检查用户名和密码") is displayed
    → User stays on /login page

## Flow 3: Product Browsing and Search

1. User navigates to /products (default: all products, page 0, size 12)
2. System calls GET /api/product/list?page=0&size=12
3. Products are displayed in a grid layout
4. Hero banner is shown above products (only when no search/tag filter)
5. User can:
   a. Search: Enter keyword in header search bar, press Enter or click 🔍
      → Route changes to /products?keyword=<term>
      → System calls GET /api/product/search?keyword=<term>&page=0&size=12
      → Search result hint shows: 搜索 "<keyword>" 的结果, 共 N 件商品
   b. Filter by tag: Click sub-nav links (今日特惠/新品上市/热销排行/品牌精选)
      → Route changes to /products?tag=<TAG>
      → System calls GET /api/product/tag/<TAG>?page=0&size=12
      → Tag label hint shows: 🔥 今日特惠 (etc.), 共 N 件商品
   c. Paginate: Click page number or 上一页/下一页
      → Page number updates, loadProducts() called, window scrolls to top
   d. Click product card → Navigate to /product/:id

## Flow 4: Product Detail View

1. User navigates to /product/:id
2. System calls GET /api/product/:id
3. Product details are displayed: name, description, price, stock, image
4. Stock ≤ 5 shows red low-stock indicator
5. User can set quantity (default: 1, min: 1, max: stock)
6. User clicks "加入购物车":
   a. If not logged in → Redirect to /login
   b. If logged in → System calls POST /api/cart with { productId, quantity }
      → SUCCESS: "已加入购物车" message
      → FAILURE: Error message displayed

## Flow 5: Cart Management

1. User navigates to /cart (requires auth)
2. System calls GET /api/cart
3. Cart items displayed in table: product image, name, unit price, quantity, subtotal, delete button
4. User can:
   a. Increase quantity: Click "+" button
      → PUT /api/cart/:itemId { quantity: current + 1 }
   b. Decrease quantity: Click "-" button (disabled when qty=1)
      → PUT /api/cart/:itemId { quantity: current - 1 }
   c. Type quantity: Change input value directly
      → PUT /api/cart/:itemId { quantity: newValue }
   d. Delete item: Click "删除" button
      → DELETE /api/cart/:itemId
      → "已从购物车中移除" message shown, cart reloaded
   e. Submit order: Click "提交订单"
      → POST /api/order {}
      → Redirect to /orders
5. If cart is empty: "购物车是空的，快去挑选商品吧！" with "去购物" button → /products
6. Bottom bar shows total price and submit button

## Flow 6: Order Creation and Viewing

1. Order is created from cart submission (see Flow 5)
2. User navigates to /orders (requires auth)
3. System calls GET /api/order/list
4. Orders displayed as cards: order ID, status badge, total amount, creation time
5. User clicks order card → Navigate to /order/:id
6. System calls GET /api/order/:id
7. Order detail shows: ID, status, creation time, total amount, item list (name, price, quantity)
8. "← 返回订单列表" link → /orders
9. If no orders: "暂无订单记录" with "去购物" button → /products

## Flow 7: Navigation

1. Header navigation:
   - Logo "🛒 E-Shop" → /products
   - Sub-nav: 全部商品 → /products, 今日特惠 → /products?tag=TODAY_DEAL, etc.
   - Search bar → /products?keyword=<term>
   - Logged in: 我的订单 → /orders, 退出登录 → logout + /login
   - Not logged in: 登录 → /login, 注册 → /register
   - 购物车 → /cart
2. Route guard: Accessing auth-required pages without token → redirect to /login
3. Default route / → redirect to /products

## Flow 8: Error Handling

1. Login failure: Display error message from response or default "登录失败，请检查用户名和密码"
2. Registration failure: Display error message from response or default "注册失败，请稍后重试"
3. Cart load failure: Display error message
4. Cart update/delete failure: Display error message
5. Order submission failure: Display error message "提交订单失败"
6. Product load failure: Display "商品加载失败" message
7. Add to cart failure: Display error message "加入购物车失败"
8. 401 response: Clear token, redirect to /login (global interceptor)
9. Image load failure: Use fallback default image
