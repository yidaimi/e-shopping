============================================
E-Shop 电商平台 应用流程文档
============================================

【一、用户注册流程】

1. 用户访问 /register 页面
2. 用户输入用户名、密码、邮箱
3. 用户点击 "注册" 按钮
4. 系统调用 POST /api/user/register 接口
5a. 注册成功：显示绿色成功提示 "注册成功，即将跳转到登录页..."，1.5 秒后自动跳转到 /login
5b. 注册失败：显示红色错误提示，包含后端返回的错误信息或默认 "注册失败，请稍后重试"

【二、用户登录流程】

1. 用户访问 /login 页面
2. 用户输入用户名和密码
3. 用户点击 "登录" 按钮
4. 系统调用 POST /api/user/login 接口
5a. 登录成功：将返回的 token (res.data) 存入 localStorage，跳转到 /products
5b. 登录失败：显示红色错误提示，包含后端返回的错误信息或默认 "登录失败，请检查用户名和密码"

【三、退出登录流程】

1. 已登录用户在 Header 中点击 "退出登录"
2. 系统清除 localStorage 中的 token
3. 跳转到 /login 页面

【四、商品浏览流程 - 列表】

1. 用户访问 /products 页面
2. 系统监听路由 query 参数（keyword、tag），组件 watch 立即执行
3. 无参数时：调用 GET /api/product/list?page=0&size=12 加载商品列表
4. 显示 Hero Banner 和 "为你推荐" 标题
5. 以网格布局显示商品卡片
6. 商品数量大于 pageSize(12) 时，显示底部分页组件

【五、商品浏览流程 - 搜索】

1. 用户在 Header 搜索栏输入关键词
2. 按 Enter 或点击搜索按钮
3. 跳转到 /products?keyword=xxx
4. 系统调用 GET /api/product/search?keyword=xxx&page=0&size=12
5. 显示 "搜索 '关键词' 的结果" 和 "共 N 件商品"
6. 隐藏 Hero Banner

【六、商品浏览流程 - 标签筛选】

1. 用户在 Header 子导航栏点击标签（今日特惠/新品上市/热销排行/品牌精选）
2. 跳转到 /products?tag=XXX
3. 系统调用 GET /api/product/tag/XXX?page=0&size=12
4. 显示标签名称（如 "🔥 今日特惠"）和 "共 N 件商品"
5. 隐藏 Hero Banner

【七、商品浏览流程 - 分页】

1. 用户点击分页组件的页码/上一页/下一页按钮
2. 系统更新 currentPage 并重新调用对应的 API
3. 页面滚动到顶部（smooth）
4. 上一页按钮在第 0 页时禁用
5. 下一页按钮在最后一页时禁用

【八、商品详情查看流程】

1. 用户点击商品卡片
2. 跳转到 /product/:id 详情页
3. 系统调用 GET /api/product/:id 加载商品详情
4. 显示商品图片、名称、描述、价格、库存
5. 默认购买数量为 1

【九、加入购物车流程】

1. 用户在商品详情页设置购买数量（默认 1，最小 1）
2. 用户点击 "加入购物车" 按钮
3a. 未登录：跳转到 /login
3b. 已登录：调用 POST /api/cart，发送 productId 和 quantity
4a. 成功：显示绿色提示 "已加入购物车"
4b. 失败：显示红色错误提示

【十、购物车操作流程】

1. 用户访问 /cart 页面（需登录，路由守卫检查）
2. 系统调用 GET /api/cart 加载购物车数据
3. 显示商品列表表格：商品名称/图片、单价、数量控制、小计、删除按钮
4. 数量控制：
   a. 点击 "+" 按钮：数量 +1，调用 PUT /api/cart/:itemId { quantity: quantity+1 }
   b. 点击 "-" 按钮：数量 -1（最小为 1），调用 PUT /api/cart/:itemId
   c. 直接输入数字：调用 PUT /api/cart/:itemId { quantity: newQty }
5. 删除商品：调用 DELETE /api/cart/:itemId，显示 "已从购物车中移除"
6. 每次操作后重新加载购物车数据
7. 底部显示合计金额和 "提交订单" 按钮

【十一、提交订单流程】

1. 用户在购物车页面点击 "提交订单"
2. 系统调用 POST /api/order
3a. 成功：跳转到 /orders 订单列表页
3b. 失败：显示红色错误提示

【十二、订单管理流程 - 列表】

1. 用户访问 /orders 页面（需登录）
2. 系统调用 GET /api/order/list 加载订单列表
3. 显示订单卡片：订单编号、状态标签、金额、创建时间
4. 点击订单卡片跳转到 /order/:id

【十三、订单管理流程 - 详情】

1. 用户访问 /order/:id 页面（需登录）
2. 系统调用 GET /api/order/:id 加载订单详情
3. 显示订单基本信息：编号、状态、创建时间、总额
4. 显示商品清单：商品名称、单价、数量
5. 底部有 "← 返回订单列表" 链接
