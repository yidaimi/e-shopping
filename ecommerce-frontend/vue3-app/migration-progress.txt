## Migration Patterns Applied
- Options API → Composition API <script setup>
- data() → ref() / reactive()
- computed → computed()
- watch → watch()
- methods → plain functions
- this.$router → useRouter()
- this.$route → useRoute()
- created() → top-level calls in <script setup>
- props → defineProps() with withDefaults()
- $emit → defineEmits()
- Vue Router 3 → Vue Router 4 (createRouter, createWebHistory)
- next() guards → return value guards
- Vue CLI → Vite
- VUE_APP_* → VITE_*
- new Vue() → createApp()
